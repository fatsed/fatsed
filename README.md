## Featured projects

### [Self-RAG Evidence Assistant](https://github.com/fatsed/self-rag-evidence-assistant)

A document question-answering assistant inspired by Self-RAG.

It retrieves relevant evidence, evaluates the evidence and generated answer, and revises answers that are not fully supported.

**Built with:** Python, Streamlit, FastAPI, Sentence Transformers, Groq

---

### [Persian Customer Support Tone Checker](https://github.com/fatsed/CustomerSupportToneChecker)

A Persian NLP project that classifies customer support messages as polite, semi-polite, or impolite.

The project includes text preprocessing, TF-IDF feature extraction, multiple machine learning models, evaluation, and a Gradio interface.

**Built with:** Python, Scikit-learn, NLP, TF-IDF, Gradio
